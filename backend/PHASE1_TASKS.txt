===========================================
PHASE 1: BACKEND - USER AUTHENTICATION
===========================================

TEAM: 2 Backend Developers
GOAL: Implement secure user registration and login system
TIMELINE: Phase 1 completion

-------------------------------------------
WHAT WE'RE BUILDING
-------------------------------------------

API Endpoints:
1. POST /auth/register  → Create new user account
2. POST /auth/login     → Login and get JWT token  
3. GET  /auth/me        → Get current user info (protected)

Database:
- SQLite database (file-based, no installation needed)
- Users table with: id, username, email, hashed_password, created_at

Security:
- Password hashing with bcrypt (never store plain passwords)
- JWT tokens for authentication
- Token expires after 30 minutes

-------------------------------------------
REQUIREMENTS TO INSTALL
-------------------------------------------

Add these to requirements.txt:
- sqlalchemy==2.0.25          # Database ORM
- python-jose[cryptography]==3.3.0  # JWT tokens
- passlib[bcrypt]==1.7.4      # Password hashing
- bcrypt==4.1.2               # Hashing algorithm
- pydantic==2.5.3             # Data validation

Then run: pip install -r requirements.txt

-------------------------------------------
FOLDER STRUCTURE TO CREATE (Modular Design)
-------------------------------------------

backend/
├── app/
│   ├── __init__.py
│   ├── database.py       # Database connection (shared)
│   ├── models.py         # All database models (User, Note, etc.)
│   ├── routers/          # Feature-based routing
│   │   ├── __init__.py
│   │   └── auth.py       # AUTH FEATURE: All auth endpoints here
│   │       - schemas (UserCreate, UserLogin, Token)
│   │       - CRUD operations (create_user, authenticate)
│   │       - endpoints (register, login, get_me)
│   │       - JWT logic (create_token, verify_token)
│   └── (Future: routers/notes.py, routers/summaries.py, etc.)
└── main.py              # Only app initialization & router imports

PRINCIPLE: Each feature = One file with everything related
- auth.py → All authentication (schemas, CRUD, endpoints, JWT)
- notes.py (Phase 2) → All notes (schemas, CRUD, endpoints)
- summaries.py (Phase 2) → All summaries (schemas, CRUD, endpoints)

WHY MODULAR?
✓ Easy to find code (all auth in one place)
✓ Easy to maintain (change auth? only edit auth.py)
✓ Easy to scale (add notes? just add notes.py)
✓ Team-friendly (Person A works on auth.py, Person B on notes.py)
✓ Less merge conflicts!

-------------------------------------------
COMMON CHALLENGES
-------------------------------------------

1. Import errors → Make sure __init__.py exists in all folders
2. Database not created → Check file path and permissions  
3. Token validation fails → Check SECRET_KEY is set
4. Password hashing slow → This is normal (security feature)
5. CORS errors → Add CORS middleware in main.py
