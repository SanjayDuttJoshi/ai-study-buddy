-------------------------------------------
DETAILED IMPLEMENTATION GUIDE
-------------------------------------------

1️⃣ SCHEMAS (Developer 1)
-------------------------------------------
File: backend/app/schemas/user.py

What to include:
- UserCreate: username, email, password
- UserLogin: username, password
- UserResponse: id, username, email (NO password!)
- Token: access_token, token_type

Use Pydantic BaseModel for validation.

2️⃣ AUTH UTILS (Developer 1)
-------------------------------------------
File: backend/app/utils/auth.py

Functions needed:
a) hash_password(password: str) -> str
   - Use bcrypt to hash passwords
   - Never store plain passwords!

b) verify_password(plain: str, hashed: str) -> bool
   - Compare plain password with hashed

c) create_access_token(data: dict) -> str
   - Create JWT token
   - Set expiration time (30 minutes)
   - Use SECRET_KEY from environment

d) decode_access_token(token: str) -> dict
   - Decode JWT token
   - Verify signature
   - Check expiration

Important:
- Use environment variables for SECRET_KEY
- Add token expiration
- Handle errors properly

3️⃣ DEPENDENCIES (Developer 1)
-------------------------------------------
File: backend/app/utils/dependencies.py

Function needed:
- get_current_user(token: str, db: Session)
  - Extract token from Authorization header
  - Decode token
  - Get user from database
  - Return user or raise 401 error

This is used to protect routes.

4️⃣ AUTH ROUTER (Developer 2)
-------------------------------------------
File: backend/app/routers/auth.py

Endpoints:

a) POST /auth/register
   - Accept: username, email, password
   - Validate: email format, password length
   - Check: username/email not already exists
   - Hash password
   - Create user in database
   - Return: user info (no password!)

b) POST /auth/login
   - Accept: username, password
   - Find user by username
   - Verify password
   - Create JWT token
   - Return: token

c) GET /auth/me
   - Protected route (requires JWT)
   - Use get_current_user dependency
   - Return: current user info

5️⃣ UPDATE MAIN.PY (Developer 2)
-------------------------------------------
File: backend/main.py

Add:
- Import auth router
- Include router: app.include_router(auth.router)
- CORS middleware (if not already there)

-------------------------------------------
ERROR HANDLING
-------------------------------------------

Common errors to handle:
1. Username already exists → 400 Bad Request
2. Email already exists → 400 Bad Request
3. Invalid credentials → 401 Unauthorized
4. Token expired → 401 Unauthorized
5. Invalid token → 401 Unauthorized
6. Missing required fields → 422 Unprocessable Entity

Use FastAPI HTTPException:
```python
from fastapi import HTTPException

raise HTTPException(
    status_code=400,
    detail="Username already exists"
)
```

-------------------------------------------
SECURITY BEST PRACTICES
-------------------------------------------

✅ DO:
- Hash all passwords (use bcrypt)
- Use strong SECRET_KEY (random, 32+ characters)
- Set token expiration
- Validate all inputs
- Use HTTPS in production
- Never log passwords

❌ DON'T:
- Store plain passwords
- Return passwords in API responses
- Use weak SECRET_KEY
- Skip input validation
- Allow SQL injection
- Trust user input
